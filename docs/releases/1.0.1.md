# 1.0.1 Release Notes

Published package version: `v1.0.1`

`1.0.1` is a backward-compatible maintenance release that qualifies the stable core contract against the current published `causal-order` package stack. It does not change runtime source or widen the payload-agnostic core.

## Qualified Stack

The exact packed `causal-order@1.0.1` artifact was qualified with:

| Package | Version | Role |
| --- | --- | --- |
| `@causal-order/transport` | `0.2.0` | transport and delivery adapter boundary |
| `@causal-order/monitor` | `0.6.0` | optional buffering, routing, capacity, and replay |
| `@causal-order/dedupe` | `1.2.0` | structured duplicate filtering before ordering |
| `causal-order` | `1.0.1` | causal ordering runtime |
| `@causal-order/testing` | `0.3.1` | workload, fault, orchestration, artifact, and verdict tooling |

The runtime delivery path is:

```text
@causal-order/transport -> [@causal-order/monitor] -> @causal-order/dedupe -> causal-order
```

Monitor is optional. Testing surrounds the installed stack and is not a runtime delivery stage.

## Qualification

The registry-backed release gate packs the exact core artifact, installs the exact published companion versions in a clean consumer, verifies package identity and dependency boundaries, and exercises:

- healthy delivery
- transport, dedupe, order, and combined outage behavior
- buffering and replay through restored dedupe
- explicitly permitted dedupe bypass
- replay failure and retry recovery
- terminal transport, monitor, lifecycle, and ordering drains
- a negative control that must return `fail_contract` and exit non-zero

The final registry matrix passed on Node.js `24.15.0`. Cross-version validation also passed the same expanded matrix on Node.js `22.23.1` and `24.15.0`.

The final packed artifact identity recorded during qualification is:

- SHA-256: `2807817d453f68afc1a7c0365c243d309465f00c31150b27268a6bb049369ddf`
- SHA-1: `0c2a41b69680d3b4d2e308f889c388998e48075e`
- 69 published files
- no runtime or bundled dependencies

The published core and the full causal-order stack require Node.js `>=22.13.0`. Node.js `22` and `24` are the supported CI lines. This aligns every stack package with monitor's built-in `node:sqlite` requirement; Node.js `18` and `20` are not supported by `v1.0.1`.

## Documentation and Release Tooling

This release:

- adds `npm run release:stack:check` as the network-backed packed-stack qualification gate
- documents all five ecosystem packages while keeping testing outside the runtime path
- aligns the README, package-surface guide, website, and sync assertions with the current stack
- corrects the Roadmap's historical `1.0` checklist to match the shipped stable release
- keeps detailed release evidence in this release note instead of expanding the package README

## Compatibility Boundary

`1.0.1` preserves the `1.0.0` runtime and declaration surface. It does not add new ordering semantics, transport behavior, persistence, dedupe policy, or domain-specific conflict resolution.

See the [`1.0.0` release notes](./1.0.0.md) for the stable contract established by the first major release.
